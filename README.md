# Property Management Module for Odoo 18

This module provides comprehensive property management capabilities for Odoo 18, including:

- Property management
- Property unit management
- Property contracts
- Maintenance requests
- Occupancy tracking

## Migration Information

This module was migrated from Odoo 17 to Odoo 18 with the following key changes:

- Converted tree views to list views (Odoo 18 requirement)
- Added mode="primary" and priority="100" attributes to form views to prevent unwanted inheritance
- Updated view_mode references from "tree" to "list"

## Installation

1. Copy the module to your Odoo 18 addons directory
2. Update the module list in Odoo
3. Install the Property Management module

## Features

- Property registration and management
- Unit tracking and categorization
- Contract management with renewal capabilities
- Maintenance request tracking
- Reporting and analytics

## Configuration

After installation, go to Property Management in the main menu to access all features.
